# Interval Lab

Start a tone, add more tones, and hear how simple number ratios make music. Built for grades 6–12 music classes.

Four tabs, each with a Simple and an Advanced mode:
- **Tuning**: tune one tone against another and hear the beats disappear.
- **Harmonics**: build the harmonic series on top of a starting tone.
- **Intervals**: hear and see intervals as number ratios.
- **Temperament**: compare just intonation with equal temperament.

One offline HTML file; nothing loads from the internet.
